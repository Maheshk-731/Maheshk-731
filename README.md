# 🚀 Featured Projects

## ♻️ Reloop — Clothing Exchange & Swap Marketplace

A full-stack marketplace that allows users to exchange clothes directly without using money.

### Features
- 🔐 User authentication
- 👕 Create and manage clothing listings
- 🔎 Category and size-based filtering
- 📍 Location-based "Near Me" matching
- 💰 Estimated swap-value calculation
- 🔄 Swap request system
- ⚖️ Fair-value comparison
- 💬 Real-time negotiation chat using Socket.IO
- 🛡️ Admin panel for moderation and analytics

### Tech Used
`React.js` `Node.js` `Express.js` `MongoDB` `Socket.IO`

🔗 [Live Demo](https://reloop-marketplace.netlify.app/)

🔗 [Source Code](https://github.com/Maheshk-731/Reloop-Project)
